# Hello Blockchain – VELSYNC Task 01

## Project Overview

Hello Blockchain is my first smart contract project, developed as part of the Velsync Blockchain & Web3 Technologies Internship.

The project demonstrates the fundamentals of Solidity by creating a simple smart contract that stores a message and allows users to update it.

## Technologies Used

- Solidity
- Remix IDE
- Remix VM

## Smart Contract Features

- Stores an initial message: "Hello Blockchain!"
- Allows users to read the stored message.
- Allows users to update the stored message.
- Provides a public function for accessing the message.

## How It Works

The `HelloBlockchain` contract contains a public string variable called `message`.

The `updateMessage()` function accepts a new string and updates the stored message.

## Deployment and Testing

The contract was compiled and deployed using Remix IDE with the Remix VM environment.

The following operations were tested successfully:

1. Reading the initial message.
2. Updating the stored message.
3. Reading the updated message.
